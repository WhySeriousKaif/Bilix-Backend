- implementing Spring Security, JWT authentication, users, roles, DTOs, repositories, services, and REST APIs;
- extending the backend for POS entities and business workflows.

## How to use the transcript

The transcript is a learning reference, not an unquestionable specification. Speech-to-text mistakes and simplified explanations should be corrected using:

1. the current source code;
2. official framework/library behavior;
3. production engineering practices.

For example, the transcript sometimes says that BCrypt “decrypts” a password. BCrypt hashes a password; it is intentionally one-way and is not decrypted during login. Similar inaccuracies should be called out in the relevant note.
